Zero-Leakage Protocol & Feature Audit

Guaranteed elimination of target leakage in PySpark pipeline

Feature Name Feature Type Intake Available? Pipeline Action Rationale
agency Categorical YES StringIndexer ➔ OneHotEncoder Known at ticket creation time
complaint_type Categorical (Top 30 + OTHER) YES StringIndexer ➔ OneHotEncoder Citizen-selected problem category
borough Categorical YES StringIndexer ➔ OneHotEncoder Incident location borough
hour, day_of_week, month Numerical / Temporal YES VectorAssembler Scaling Submission timestamp attributes
closed_date Timestamp (Target Leakage) NO (Post-Resolution) DROPPED STRICTLY Occurs after ticket closure; would leak resolution duration
status Categorical ("Closed", "Pending") NO (Post-Resolution) DROPPED STRICTLY Reflects post-dispatch outcome
resolution_description Text (Agency Action) NO (Post-Resolution) DROPPED STRICTLY Only documented after agency dispatch/inspection
